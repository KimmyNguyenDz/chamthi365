# Chamthi365 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clone chức năng app PWA chấm phiếu trắc nghiệm "Chấm Phiếu Học Giỏi" thành Chamthi365 + tính năng QR (phiếu in QR mã đề/SBD, QR nạp đáp án).

**Architecture:** React+TS+Vite PWA offline-first, IndexedDB local, 3 Web Worker OMR (port thuật toán từ `_research/may-cham.worker-*.js`), thư viện phiếu mirror tĩnh, Supabase+Drive sync, tự parse/ghi OOXML cho trộn đề.

**Tech Stack:** React 18, TypeScript, Vite, vite-plugin-pwa, idb, xlsx (SheetJS), pdfjs-dist, jszip, jsqr + BarcodeDetector, qrcode, @supabase/supabase-js, lucide-react, vitest, fake-indexeddb.

**Spec:** `docs/superpowers/specs/2026-11-23-chamthi365-design.md` — đọc cùng plan này. Reference gốc: `_research/` (bundle.js/css, workers, mucluc.json, khuon_*.json, mau/).

## Global Constraints

- Mọi UI text tiếng Việt, tone "thầy cô" như app gốc (`_research/vi_strings.txt` là kho copy gốc — bám sát wording).
- Branding: tên "Chamthi365", không xuất hiện "Chấm Phiếu Học Giỏi"/"Thái Minh Nguyên"/"hoc-gioi" trong UI và file xuất. PDF mirror giữ nguyên.
- Fonts: Baloo 2 + Be Vietnam Pro (Google Fonts). Palette: `#7ccfff #a8e0ff #d4f1ff #ffcf3f #36c46b #1f2544`; nút viền 3px `#1f2544`, shadow cứng, radius lớn.
- Hash router: `#/`, `#/tao`, `#/bai/:id`, `#/bai/:id/sua|dap-an|hoc-sinh|camera|cham|xem`, `#/bai/:id/phieu/:pid`, `#/phieu`, `#/tron`, `#/mau`, `#/cai-dat`.
- Không thêm dependency ngoài danh sách Tech Stack.
- IDB db name `chamthi365`, stores `bai, phieu, anh, hang, meta` — schema giữ nguyên spec §5.
- Node 24, `npm` (Windows). Test: `vitest run` (environment node; OMR test trên `Uint8Array` tổng hợp, không cần canvas).

## Review Focus

1. QR phiếu không đọc được → vẫn phải chấm được bằng ô tô + cờ cần xem (Task 18).
2. PDF scan 2 phiếu/trang (khuôn có `clip`) → tách đúng từng nửa trang (Task 12).
3. File `.doc` (Word cũ) / docx hỏng → báo lỗi đúng tiếng Việt, không crash (Task 16).
4. Ảnh quá lớn làm worker crash → bắt `onerror`, báo "Máy chấm gặp sự cố…" không mất hàng đợi (Task 11).
5. Mất mạng khi đồng bộ → ghi `hang`, tự đẩy lại khi có mạng (Task 19).
